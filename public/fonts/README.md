# iYokai Fude — original display family

Fude, Fude Light and Fude Bold have original proportional brush outlines,
independent attacks, variable pressure, tapered exits, curved bowls, actual
lowercase letters, accented vowels and katakana ミ. Source generator:
`tools/build_fude_font.py`. All font files are served locally.

No binaries, glyph outlines, tracing, or modified files from Hoshiko Satsuki,
Harukaze, Kashima Brush or Hiro Misake were used. The four typefaces were visual
references only. Fude is not a merger or modification of their font software.
The old Brush, Ink, Wind studies are retained but are no longer the default.
